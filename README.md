# 《小兵传奇》星际战争游戏 — NLP 课程项目

NLP 课程 project，方向是 AI + gaming。做一个基于玄雨《小兵传奇》设定的单机剧情游戏：战略层走星图、关系网、剧情分支，战斗层是参照《战舰世界》手感的实时 3D 遭遇战。技术栈 Unity + Blender，目前处于设计与原型阶段，尚未进入正式开发。

## 打开原型

`proposal/原型设计/prototype.html` 是单文件，直接用浏览器打开即可，无需构建。

也可以起本地服务器：

```bash
python -m http.server 8765 --bind 127.0.0.1 --directory proposal/原型设计
```

原型有五个视图（星图 / 关系网 / 作战 / 资源 / 剧情）。两个值得试的交互：

- 点击右上角阵营徽章，循环切换联邦 / 银鹰 / 家族，观察关系网和资源可见度如何随配置变化——这是"同一套系统 + 配置驱动差异"的直观演示。
- 切到作战页，点击战场移动准星开火，看弹道轨迹与命中反馈；WASD 改航速舵角，空格齐射；右侧四个分队可下指令。

原型只演示信息架构与交互流程，不接真实规则引擎，也不做真正的 3D 渲染。

## 设定来源

所有游戏设定的原始出处是 `参考资料/小兵传奇.txt`。三份分析文档按主题把它拆开，每条结论都附了章号，可直接回原文核对。

章号指文件行首"第 N 章"的**总编号**。小说正文里卷内小节标题会重置（比如出现多个"第三章"），用总编号定位才不会混淆。

## 设计要点

**三阵营共享底层。** 联邦、银鹰、家族三套路线的关系网、作战体系、星际地图是公共模块，阵营差异由配置表驱动，不写三套逻辑。成长路线同构：家族靠资源膨胀，另两条靠军功；前期联邦 / 银鹰的资源由高层代管，玩家专注作战，后期晋升高层后汇合到同一套经济系统。

**战斗层与战略层窄接口。** 战略层传入敌我编成、战场类型、剧情目标；战斗层回传战损、军功、耗时、剧情标记。战斗内部怎么跑，战略层不关心。这条边界让战斗模块可以独立砍功能而不牵连剧情和关系网。

**战斗群映射。** 战舰世界里一艘舰的主炮 / 副炮 / 侦察机 / 舰载机，对应小说的主舰 / 僚舰 / 巡逻舰 / 副舰，做成四个固定分队槽位。玩家直接驾驶主舰，其余三支用指令调度，既有舰队层次感又不用做逐艘操控的 RTS。
